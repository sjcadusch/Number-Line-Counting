# Multiplication Facts

Standalone JavaScript project for practicing one multiplication fact family at a time.

## Features

- Enter a single **fact family number (1–12)**.
- Set display **speed in milliseconds**.
- Play equations in **forwards**, **backwards**, or **random** order.
- Displays exactly 13 equations (0 through 12) one line at a time.
- Compact control area so all 13 facts can fit on a typical laptop screen.
- Background color `#BCFCBF`.

## Run locally

```bash
python3 -m http.server 8000
```

Then visit <http://localhost:8000>.
